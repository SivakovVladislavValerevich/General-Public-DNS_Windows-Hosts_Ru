# Hosts - адреса DNS-сервисов
Набор IPv4- и IPv6-адресов с привязками к доменным именам для локального файла hosts.

# Назначение
Файл задаёт локальные соответствия «IP-адрес → имя хоста». Важно: добавление этих записей в hosts не переключает системный DNS-сервер - его необходимо настраивать отдельно в параметрах сети или используемого приложения.

# Ограничения
Актуальность адресов и подписей не проверена до конца.
Привязка домена к конкретному IP переопределяет обычное разрешение имени и при неверном адресе может нарушить доступ к ресурсу.
